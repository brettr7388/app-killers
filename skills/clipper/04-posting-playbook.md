# Posting

The clip is half the job. This half is why most clip accounts stall at 200 views.

## Captions (the text on the post, not the burned ones)

The caption's only job is to make someone watch the first two seconds *again*.

**Describe the tension, never the outcome.**
- ✅ "he said the door was locked…"
- ❌ "guy gets scared when door opens"

The second one told them the ending. There's nothing left to watch for.

Formulas that work, in rough order of reliability:

1. **Unfinished setup** — "he had one job…"
2. **Quote the moment** — "'there is NO way that just happened'"
3. **Wrong-side POV** — "pov: you're the guy who has to explain this"
4. **Stakes** — "$400 on the line and he does this"
5. **Confident-then-wrong** — "he was so sure. he was so wrong."

Keep it under ~90 characters. No links in Instagram captions, ever — they suppress
reach. Put the link in the bio instead.

## Hashtags — rotate every single post

Posting the identical hashtag block on every upload is the most common self-inflicted
reach problem on both TikTok and Instagram. Build 4–5 sets and rotate them; never
reuse the same block twice in a row.

```
SET A  #gaming #clips #fyp #funny #streamer
SET B  #gamingclips #viral #lol #twitch #fail
SET C  #funnymoments #foryou #gamer #clip #reaction
SET D  #streamerclips #fyp #comedy #gaming #edit
```

5–7 tags is the sweet spot. Two should be broad (#fyp, #viral), three should be
specific to the actual content (#minecraft, #warzone, the streamer's name).

## Cadence and safety

- **Max 3–4 posts per day per account.** More looks automated and gets throttled.
- **At least 3 hours between posts.** Bursts are the clearest bot signal there is.
- **Post at consistent times.** Pick two or three slots and keep them. The algorithm
  learns your audience's window; moving around resets that.
- **Never post a clip with another creator's watermark.** Both platforms
  down-rank recycled content, and it's the fastest way to a strike.

## If reach suddenly collapses

Almost always one of: identical hashtag blocks, a burst of posts too close together,
reposted watermarked content, or a copyright claim on background music. Recovery
protocol:

1. Stop posting for 48 hours. Completely.
2. Delete the last 2–3 posts if they were watermarked or duplicated.
3. Resume at **one** post per day, fresh hashtag set each time, for a week.
4. Only go back to 3/day after views return to baseline.

This works, but it takes two weeks. Not triggering it is much cheaper.

## Which platform gets which cut

Same clip, three different top-of-post treatments:

- **TikTok** — caption carries the hook. Burned captions matter most here.
- **Reels** — same file works; keep captions higher (Reels' UI eats more bottom).
- **YouTube Shorts** — the *title* carries the hook, not the caption. Retitle every
  clip for Shorts: "He Was SO Sure The Door Was Locked" reads as a title; "he said
  the door was locked…" reads as a TikTok caption and won't rank.

## The only metric that matters early

Watch time percentage, not views. A 20-second clip held to 85% will get pushed; a
40-second clip held to 30% won't, even if it got more views today. When a clip
underperforms, the fix is almost always **cut two seconds off the front**.
